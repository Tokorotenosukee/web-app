# おはなし

発声が難しい人向けの、日本語意思伝達アプリのMVPです。外部サーバーや外部音声APIは使わず、端末のWeb Speech API・localStorage・IndexedDBだけで動作します。

このプロジェクトは、家族・支援者・開発者から改善提案を受けるためにオープンソースで公開しています。ライセンスはMIT Licenseです。

## 起動方法

```bash
npm install
npm run dev -- --host 0.0.0.0
```

表示されたURLをブラウザで開きます。型チェックは `npm run typecheck`、本番ビルドは `npm run build` です。

## iPadで確認する方法

同じWi-Fiに接続したMac/PCから開発サーバーを起動し、ターミナルに表示される `http://<MacのIP>:5173/` をiPad Safariで開きます。共有メニューの「ホーム画面に追加」でPWAとして確認できます。横向きを優先していますが、縦向きにも対応しています。

確認項目：定型文の1タップ読み上げ、自由入力と再読み上げ、停止、履歴の再生・削除、定型文編集、設定保持、JSONバックアップ、オフライン再起動。

## プライバシー

- 入力した文章、定型文、設定、履歴は端末内に保存します。
- アプリから外部サーバーへ発話内容を送信する機能はありません。
- 端末やブラウザのバックアップ・同期設定による保存先は、このアプリから制御できません。
- IssueやPull Requestには、実際の氏名・住所・病名・発話内容などを記載しないでください。

## 現時点の注意点

- 音声はiPad SafariのOS設定・音声パックに依存します。日本語音声が選択できない場合は、iPadの「設定 > アクセシビリティ > 読み上げコンテンツ」等で日本語音声を追加してください。
- Web Speech APIはブラウザやホーム画面追加後のPWAで挙動差があります。音声のオフライン動作は実機で確認してください。MVPでは利用できない場合に画面へエラーを表示します。
- 定型文のカテゴリ名編集・並べ替えは次の拡張項目です。現MVPでは文章の追加・編集・削除とカテゴリ切替を実装しています。
- 画面を閉じる前の未保存入力はブラウザ仕様により保持保証しません。入力欄に残っている文章は読み上げ後も保持されます。
- 医療機器ではありません。緊急時の連絡手段や医療上の判断を代替するものではありません。
